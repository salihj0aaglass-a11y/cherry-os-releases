# Cherry OS releases

Finished versions of Cherry OS, made by Cherry. Every Cherry OS checks here
for updates and installs them by itself.

- `cherry-os-latest.zip` — the newest version, ready to run (no source code)
- `latest-version` — its version number

Cherry Board (the smartboard version) updates from the `board/` folder:

- `board/latest.json` — the newest Cherry Board version and its checksum
- `board/cherry-board-X.Y.Z.tar.gz` — that version, ready to run
